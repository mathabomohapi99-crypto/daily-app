# Sprint 1 Review — CampusFlow

**Sprint Goal:** By the end of Sprint 1, a student can fully manage a task's lifecycle on the CampusFlow board — create, edit, categorize, complete, and see it persist.

## What's genuinely demoable
- The 3-column board (To Do, In Progress, Done) is built and working — this story is fully Done.
- Adding a new card with a title and description works in the To Do column — this story is In Progress; it currently lacks edit, delete, move, and persistence.

## What's not yet demoable
Edit, delete, move, mark-complete, categorize-by-type, and data persistence are all still To Do — no code exists for these yet.

## Honest check against the Sprint Goal
The Sprint Goal describes a full task lifecycle (create, edit, categorize, complete, persist). Right now only a slice of "create" is working. The goal was not met this sprint — this is a realistic snapshot of early progress, not a finished lifecycle.
